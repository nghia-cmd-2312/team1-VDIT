## Thay đổi
* Chuyển từ dùng ```file system access api``` sang ```indexedDB```
* Xóa nút chọn thư mục vì không cần thiết

## Hướng dẫn dùng
1. Chọn file/Tạo file *(chọn file bằng cách click vào file)*
2. Sửa
3. Lưu/Xóa

* *```<aside>```trên điện thoại không ổn nhưng sẽ sửa sau*
