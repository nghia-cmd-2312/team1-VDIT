## Thay đổi
* Cái patch 1 là bản cũ. Đây là patch 2
* Chuyển từ dùng ```localStorage``` sang ``file system access api``
* Giữ nguyên lịch sử báo cáo trong trang HS
* Cho lịch sử báo cáo vào trang giáo viên và làm nó to hơn

## Hướng dẫn dùng
### Giáo viên:
1. Mở thư mục (phải cấp quyền truy cập lần đầu, những lần tiếp theo không cần cấp quyền nữa)
2. Chọn file/Tạo file *(chọn file bằng cách click vào file)*
3. Lưu
### Học sinh:
1. Mở thư mục
2. Xem

### Note:
* *Cái ```toggleDetail``` giờ mở luôn file, nhưng trông hơi kì*
* *Tôi chưa thử trên điện thoại (sẽ update tình hình)*
* *Cách đọc JSON cũ trong ```HIỂN THỊ DANH SÁCH BÁO CÁO``` không tương thích với định dạng mới*
* *Tôi ko biết còn để lại chút gì của code cũ không nhưng chắc là hết r*
